# La Dernière Perle

Dépôt de distribution Windows et Android du jeu La Dernière Perle.
Les fichiers seront proposés dans les Releases ; les sources de développement
ne sont pas publiées dans ce dépôt.

La version 2.1.0 ajoute les événements Halloween et Noël. Sa première livraison
est en cours de validation : tests automatisés effectués, tests sur PC Windows
et Android physiques encore nécessaires.

Un APK marqué « Test » utilise un package et un certificat distincts. Il ne
remplace pas la V1 et ne doit pas être renommé comme APK de distribution.
Une mise à jour de l'application Android existante nécessite sa clé de signature
d'origine. Les brouillons de Release ne déclenchent pas la notification de mise
à jour dans le jeu.
